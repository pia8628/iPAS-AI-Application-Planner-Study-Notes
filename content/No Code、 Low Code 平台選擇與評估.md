# 6 項關鍵因素

 1. 目標用戶與技術需求
	 1. 使用者是否有技術背景？
	 2. 要解決的問題是簡單工作流或需要複雜控制？
	 3. No code 或 Low code
 2. 功能與擴展性
	 1. 系統整合能力 (整合現行 CRM、ERP)
	 2. 高度自定性
 3. 安全性與合規性
	 1. 資料安全和隱私保護，如資料加密、身份驗證等
	 2. 權限管理
 4. 成本效益
	 1. 總擁有成本（Total Cost of Ownership, TCO）：考量平台的購買、維護、培訓等相關成本，評估其對企業的整體財務影響，避免隱性費用。
	 2. 投資回報率（Return On Investment, ROI）：衡量平台在縮短開發週期、產品上市時間，提升開發效率等效益，確保投資具有實際價值。
 5. 技術支援與社群資源
	 1. 技術資源 (線上論壇、專業客服)
	 2. 用戶社群活躍度 (能否提供經驗分享)
 6. 市場評價與案例
	 1. 用戶評價
	 2. 成功案例

# 3 題模擬練習題

### 題目 1  
**在選擇低代碼（Low code）或無代碼（No code）平台時，下列哪一項最應優先考慮？**

A. 使用者是否具備技術背景，以及要解決的是簡單流程還是複雜控制  
B. 平台的市場評價與用戶成功案例  
C. 技術支援與活躍的用戶社群  
D. 資料安全管理與權限控制  

**正確答案：** A  

**詳解：**  
選擇 Low code 或 No code 平台時，首先要根據目標用戶的技術背景與需求判斷。技術背景不同，適用的平台類型不同；而解決的問題如果是簡單工作流，No code 可能更適合；如果需要複雜控制，則可能需要 Low code 平台以提供更多自定義能力。這是整體決策的基礎。

### 題目 2  
**在企業導入低代碼或無代碼平台時，以下哪一項屬於評估“成本效益”的核心指標？**

A. 線上論壇與專業客服的可用性  
B. 平台的資料加密與身份驗證機制  
C. 總擁有成本（TCO）與投資回報率（ROI）  
D. 系統整合的靈活性與高度自定義能力  

**正確答案：** C  

**詳解：**  
成本效益的評估主要關注總擁有成本（TCO）及投資回報率（ROI）。TCO涵蓋平台的購買、維護、培訓等成本，ROI衡量平台帶來的效益，如開發效率提升和縮短上市時間，都是企業決策的重要指標。

### 題目 3  
**針對資料安全和合規性的需求，以下哪一項措施不是重點考量？**

A. 資料加密  
B. 權限管理  
C. 用戶社群活躍度  
D. 身份驗證  

**正確答案：** C  

**詳解：**  
資料安全與合規的重點包括資料加密、身份驗證與權限管理，這些措施能有效保護企業數據及用戶隱私。而用戶社群活躍度屬於技術支援與社群資源的評估範疇，與資料安全無關。
